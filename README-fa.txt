ساخت APK بدون Android Studio (با GitHub Actions، رایگان)

1. در github.com یک مخزن (repository) جدید بساز. خصوصی هم اشکالی ندارد.
2. همهٔ محتوای این زیپ را داخلش آپلود کن. پوشهٔ مخفی .github هم باید آپلود شود، پس کل پوشه را با drag and drop بکش.
3. به تب Actions برو، گزینهٔ «Build APK» را انتخاب کن و Run workflow را بزن. با هر push هم خودکار اجرا می‌شود.
4. بعد از حدود ۵ تا ۱۰ دقیقه، از پایین صفحهٔ اجرا فایل pixel-notes-apk را دانلود کن.
5. داخلش app-debug.apk است. آن را روی گوشی نصب کن (نصب از منبع ناشناس را فعال کن).

نسخهٔ بدون APK: پوشهٔ www را روی هر هاست HTTPS بگذار و در Chrome اندروید گزینهٔ Install app را بزن.

نکته: یادداشت‌ها فقط روی همان گوشی ذخیره می‌شوند. قبل از حذف اپ از دکمهٔ پشتیبان‌گیری کد بگیر.
